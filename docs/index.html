Everything you need for local HTTPS

Inspired by Ophiuchi, re-architected in pure Rust so it runs natively on macOS and Windows with tiny memory usage and zero Docker overhead.

Native Rust HTTPS Proxy

Built on tokio, hyper, and tokio-rustls. Full SNI, HTTP/1.1, HTTP/2, WebSocket/HMR tunneling, live route hot-reload, and HTTP → HTTPS redirection.

Trust-Once Local Root CA

Generates an ECDSA P-256 Local Root CA trusted once in macOS System Keychain or Windows User Root Store. Every new domain is auto-signed and trusted immediately.

Safe Managed Hosts Sync

Updates /etc/hosts or Windows drivers\etc\hosts inside dedicated markers with automatic timestamped backups and native admin/UAC prompts.

Optional Blind-TLS Tunnels

Tunnel Edition embeds opentunnel to expose any local proxy at a public HTTPS URL while terminating TLS locally on your machine.

Live Request Logs

Inspect real-time HTTPS and WebSocket traffic with status codes, upstream targets, latency in ms, instant search, and pause/clear controls.

System Tray & Diagnostics

Keep the proxy running quietly in the macOS menubar or Windows tray, and check CA trust, hosts sync, and port 443/80 health at a glance.

Two Editions. Pick Your Footprint.

Both editions share the exact same Rust HTTPS core and install side-by-side cleanly on macOS and Windows.

Standard Edition

Ophiuchi-rs

Lightweight, 100% local-only SSL reverse proxy with zero external network or tunnel dependencies compiled in.

  • Native Rust HTTPS, HTTP/2 & WebSocket reverse proxy
  • Trust-once Local Root CA (macOS Keychain & Windows Cert Store)
  • Managed hosts file sync with automatic backups
  • Proxy groups, live request logs, diagnostics & system tray

Up and running in 3 steps

1

Trust Local Root CA

Click Trust Root CA once. macOS or Windows registers Ophiuchi-rs's local CA so browsers show a green padlock automatically.

2

Add a Domain & Sync Hosts

Map api.myapp.test to 127.0.0.1:3000 and click Sync Hosts. Your existing hosts entries are backed up and preserved.

3

Start Proxy (or Share Publicly)

Start the built-in Rust proxy on port 443 — or toggle Public Tunnel in Tunnel Edition to share over a real public HTTPS URL.
